# Control Web - VIP License Key Management

Firebase Realtime Database Control Panel for Android VIP Panel.

## Features
- Realtime license key generation with custom durations
- Device limits & HWID management / reset
- Instant key status toggle (Active / Revoked)
- Realtime session security & password change enforcement

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
